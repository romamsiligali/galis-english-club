# Gali’s English Club

Eight original 30-minute English lessons for Grade 3 learners working in pairs, with individual notebook writing. Free static website; no AI API, accounts or backend.

Progress is saved in the browser. Six-digit continuation codes restore only the lesson and step on another computer, not answers or personal information.

To publish: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Open index.html locally or serve this folder with a static web server.
