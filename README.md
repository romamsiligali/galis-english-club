# Gali’s English Club

Eight original 30-minute English lessons for Grade 3, working in pairs with individual notebook writing.

Free static website with prepared feedback; no AI service, paid API, accounts or backend. Progress stays in the browser. Six-digit continuation codes restore the lesson and step on another computer, without answers or personal information.

Publish: Settings → Pages → Deploy from a branch → main → /(root) → Save.

No personal student data should be entered. The teacher page is public and displays only progress stored in the current browser.
